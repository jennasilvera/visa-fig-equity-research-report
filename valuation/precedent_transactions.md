# Precedent Transaction Analysis

## Purpose

Precedent transactions provide context for how strategic acquirers value payments infrastructure assets. For Visa, precedents are not the primary valuation method because there is no perfect precedent for a scaled global card network. However, they are useful for FIG investment banking because they show how the payments profit pool is valued in M&A.

## Why Precedents Are Imperfect for Visa

Visa is a unique public network with global scale, high margins, brand trust, and limited direct credit risk. Most payments transactions involve processors, merchant acquirers, gateways, software platforms, issuer processors, fraud tools, or infrastructure assets.

Therefore, precedents should be used for context, not as the primary method for Visa's valuation.

## Relevant Transaction Categories

### Merchant Acquiring and Processing

Examples:

- Fiserv / First Data
- FIS / Worldpay
- Global Payments / TSYS
- Worldpay-related transactions

Why relevant:

These transactions show how strategic buyers value scale in acquiring, merchant distribution, processing, and payment acceptance.

### Issuer Processing and Infrastructure

Examples:

- Visa / Pismo
- Marqeta-related public-market reference
- Processor acquisitions involving issuing infrastructure

Why relevant:

Issuer processing matters because Visa's future may include more infrastructure around card issuing, fintech enablement, and embedded finance.

### Fraud, Risk, Data, and Identity

Examples:

- Visa / Featurespace
- Mastercard risk, cyber, or data acquisitions
- Fraud prevention and authentication software transactions

Why relevant:

These assets help explain the strategic value of Visa's VAS expansion.

## Required Data Fields

| Field | Description |
|---|---|
| Announcement Date | Date transaction was announced |
| Acquirer | Buyer |
| Target | Company acquired |
| Category | Acquiring, processing, fraud, infrastructure, etc. |
| Transaction Value | Enterprise or equity value |
| Revenue | Target revenue |
| EBITDA | Target EBITDA |
| EV / Revenue | Transaction value divided by revenue |
| EV / EBITDA | Transaction value divided by EBITDA |
| Strategic Rationale | Why the buyer acquired the asset |
| Relevance to Visa | How the transaction informs Visa analysis |

## Professional Interpretation

The correct conclusion is not that Visa should trade at the median precedent multiple. The correct conclusion is:

> Precedent transactions show how strategic buyers value specific payments capabilities. They help frame the value of Visa's VAS, money movement, fraud, risk, and processing capabilities, but they are not the primary valuation anchor for Visa's core network.

## Interview Talking Point

> I included precedent transactions because this is a FIG/payments project, but I would not over-weight them. Visa is too unique for precedents to drive the target price. I use precedents mainly to understand the strategic value of payments infrastructure assets.
