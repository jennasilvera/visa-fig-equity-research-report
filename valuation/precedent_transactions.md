# Precedent Transaction Analysis

## Purpose

Precedent transaction analysis provides context for how strategic and financial buyers value payments assets. For Visa, precedents are not the primary valuation method because Visa is a unique scaled global network, but they are useful for understanding payments infrastructure valuation.

## Relevant Transaction Categories

### Merchant Acquiring and Processing

- Fiserv / First Data
- FIS / Worldpay
- Global Payments / TSYS
- Worldpay-related transactions

### Payments Infrastructure

- Visa / Pismo
- Mastercard / Nets account-to-account assets
- Issuer processor and gateway acquisitions

### Fraud, Risk, Data, and Identity

- Visa / Featurespace
- Mastercard risk/cyber/data acquisitions
- Fraud prevention and authentication software transactions

## Required Data Fields

| Field | Description |
|---|---|
| Announcement Date | Date transaction was announced |
| Acquirer | Buyer |
| Target | Seller / target company |
| Category | Merchant acquiring, issuer processing, fraud, infrastructure, etc. |
| Transaction Value | Enterprise value or equity value |
| Revenue | Target revenue |
| EBITDA | Target EBITDA |
| EV/Revenue | Transaction value / revenue |
| EV/EBITDA | Transaction value / EBITDA |
| Strategic Rationale | Why the buyer acquired the asset |
| Relevance to Visa | What the transaction says about Visa's valuation or strategy |
