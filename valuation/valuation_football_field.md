# Valuation Football Field

## Purpose

A football-field valuation summarizes Visa's implied share price across multiple valuation methodologies. This is a standard investment banking and equity research output because it shows valuation range rather than false precision.

## Valuation Methods to Include

| Method | Purpose |
|---|---|
| DCF - Perpetuity Growth | Intrinsic value based on long-term cash flow |
| DCF - Exit Multiple | Intrinsic value using market-based terminal value |
| Forward P/E | Primary public equity valuation method |
| EV/EBITDA | Capital-structure-neutral comp method |
| FCF Yield | Cash-flow valuation context |
| Historical P/E Range | Visa's own trading history |
| SOTP | Strategic value of core network plus services/money movement |
| Bear / Base / Bull Scenarios | Risk/reward framing |

## How Investors Use It

Investors use the football field to see:

- Whether the target price is supported by multiple methods
- Whether downside is acceptable
- Whether upside depends on aggressive assumptions
- Which methods produce the highest and lowest values
- Whether the recommendation is balanced

## Professional Output

The football field should show:

1. Low valuation
2. High valuation
3. Selected target price
4. Current share price
5. Implied upside / downside
6. Notes on which methods carry the most weight

## Interpretation Standard

The final report should not simply average every method. Some methods deserve more weight.

For Visa:

- DCF and forward P/E should receive the most weight.
- EV/EBITDA and FCF yield should provide support.
- Precedents should provide context but low weighting.
- SOTP should be used to explain services optionality.

## Interview Talking Point

> I use the football field to show that my target price is not dependent on one aggressive assumption. For Visa, I would overweight DCF and forward P/E, use EV/EBITDA and FCF yield as cross-checks, and treat precedents as context rather than a direct valuation anchor.
