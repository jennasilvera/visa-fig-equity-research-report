# DCF Valuation Summary

## Purpose

The DCF valuation estimates Visa's intrinsic equity value based on projected unlevered free cash flow. For a high-quality payments network like Visa, the DCF is useful because it forces the analyst to explicitly underwrite revenue growth duration, operating margin durability, free cash flow conversion, reinvestment needs, and terminal value assumptions.

## Why DCF Matters for Visa

Visa is often valued using P/E and EV/EBITDA because it is a mature public company with strong earnings visibility. However, a DCF is still important because Visa's valuation depends heavily on long-term assumptions:

- How long can Visa grow above GDP?
- Can operating margins remain elevated?
- Can client incentives remain manageable?
- Can value-added services extend the growth runway?
- How much terminal value is justified?
- What discount rate is appropriate for a high-quality but regulated payments network?

## DCF Structure

The V2 model should calculate:

1. Net revenue
2. Operating income
3. Tax-affected EBIT / NOPAT
4. Depreciation and amortization
5. Capital expenditures
6. Change in working capital
7. Unlevered free cash flow
8. Present value of explicit forecast cash flows
9. Terminal value
10. Enterprise value
11. Equity value
12. Implied equity value per share

## Key Assumptions

| Assumption | Why It Matters |
|---|---|
| Revenue CAGR | Main driver of long-term value |
| Operating Margin | Captures scale benefits, VAS mix, incentives, and cost pressure |
| Tax Rate | Converts operating income to NOPAT |
| D&A % Revenue | Non-cash expense add-back |
| Capex % Revenue | Reinvestment intensity |
| Working Capital | Cash conversion and timing |
| WACC | Discount rate for future cash flows |
| Terminal Growth | Long-term steady-state growth |
| Exit Multiple | Market-based terminal value cross-check |
| Diluted Shares | Converts equity value to per-share value |

## Sensitivity Tables Required

The model should include:

1. WACC vs terminal growth
2. WACC vs exit EBITDA multiple
3. Revenue CAGR vs operating margin
4. Client incentives vs operating margin
5. Cross-border growth vs revenue growth
6. Terminal P/E vs EPS estimate

## Professional Interpretation

A strong DCF discussion should not pretend precision. Instead, it should explain which assumptions matter most.

For Visa, the most important DCF drivers are:

- Terminal value assumptions
- Revenue growth duration
- Operating margin durability
- Free cash flow conversion
- Discount rate
- Long-term take-rate stability

## Interview Talking Point

A strong answer in an interview:

> I used the DCF not because it gives a single precise answer, but because it forces me to underwrite the durability of Visa's economics. The key question is whether Visa can sustain premium growth and margins despite regulatory pressure, client incentives, and alternative rails. The DCF makes those assumptions explicit.
