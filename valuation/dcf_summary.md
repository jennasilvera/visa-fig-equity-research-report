# DCF Valuation Framework

## Purpose

The DCF valuation estimates Visa's intrinsic equity value based on projected unlevered free cash flow.

## Core DCF Structure

1. Forecast net revenue
2. Forecast operating income
3. Calculate tax-affected EBIT / NOPAT
4. Add depreciation and amortization
5. Subtract capital expenditures
6. Adjust for change in working capital
7. Calculate unlevered free cash flow
8. Discount FCF using WACC
9. Calculate terminal value
10. Bridge enterprise value to equity value
11. Divide by diluted shares outstanding

## Required Assumptions

| Assumption | Purpose |
|---|---|
| Revenue CAGR | Main growth driver |
| Operating Margin | Reflects scale, mix, incentives, and investment |
| Tax Rate | Converts EBIT to NOPAT |
| D&A % Revenue | Non-cash expense add-back |
| Capex % Revenue | Reinvestment requirement |
| NWC % Revenue | Cash conversion impact |
| WACC | Discount rate |
| Terminal Growth Rate | Perpetuity growth assumption |
| Exit Multiple | Alternative terminal value methodology |
| Diluted Shares | Converts equity value to per-share value |

## Required Sensitivities

- WACC vs terminal growth
- WACC vs exit multiple
- Long-term revenue growth vs operating margin
- Client incentives vs operating margin
- Cross-border growth vs revenue CAGR
