# Sum-of-the-Parts Valuation

## Purpose

A sum-of-the-parts valuation helps separate Visa's mature core network from faster-growing services and money movement opportunities.

Visa is usually valued as one consolidated business, but SOTP is useful because investors increasingly debate whether Visa should be viewed only as a card network or as a broader transaction infrastructure company.

## Suggested Visa SOTP Segments

| Segment | Valuation Basis | Rationale |
|---|---|---|
| Core Consumer Payments Network | EBIT or revenue multiple | Durable global network cash cow |
| Commercial / B2B Payments | Revenue or EBIT multiple | Long runway for digitization |
| Value-Added Services | Revenue or EBIT multiple | Faster-growing services layer |
| Visa Direct / Money Movement | Revenue multiple | Non-carded money movement optionality |
| Net Cash / Other | Balance sheet value | Enterprise value to equity value bridge |

## Why SOTP Matters

A single blended multiple may understate the value of faster-growing business lines if VAS and money movement scale faster than the core network.

A SOTP also helps answer:

- How much of Visa's value comes from the core network?
- How much option value should be assigned to VAS?
- Is Visa Direct material enough to affect valuation?
- Does Visa deserve a higher multiple if services become a larger mix?

## Risks of SOTP

The SOTP approach can overstate precision because Visa does not disclose all segment-level profitability in the way an analyst would ideally want.

Therefore, SOTP should be used as a supporting method, not the main target-price driver.

## Professional Interpretation

A good SOTP conclusion:

> The SOTP framework is useful directionally. It shows that if VAS and money movement are valued using higher-growth infrastructure multiples, Visa's consolidated multiple may be easier to justify. However, because segment profitability is not fully disclosed, the SOTP should be treated as a strategic valuation framework rather than a precise standalone valuation.

## Interview Talking Point

> I used SOTP to reflect that Visa may not be a single-multiple story forever. The core network is a premium cash cow, while VAS and Visa Direct may deserve a different growth and multiple framework.
