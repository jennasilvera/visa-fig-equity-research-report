# Trading Comparable Company Analysis

## Purpose

Trading comps benchmark Visa's valuation against publicly traded payments, networks, processors, and fintech infrastructure companies.

## Peer Groups

### Global Networks

- Visa
- Mastercard
- American Express
- Discover / Capital One, where applicable

### Merchant Acquirers and Processors

- Fiserv
- Global Payments
- Shift4
- Adyen
- Toast

### Digital Wallets and Fintech Platforms

- PayPal
- Block

### Infrastructure and Issuer Processing

- FIS
- Jack Henry
- Marqeta

## Metrics to Include

| Metric | Why It Matters |
|---|---|
| Market Cap | Size comparison |
| Enterprise Value | Capital-structure-neutral valuation |
| Revenue Growth | Growth profile |
| EBITDA Margin | Profitability |
| Operating Margin | Core operating efficiency |
| P/E | Common ER valuation metric |
| EV/EBITDA | Cross-company valuation comparison |
| FCF Yield | Cash generation relative to market value |
| Net Cash / Debt | Balance sheet profile |

## Output

The final model should calculate Visa's implied valuation using:

- Peer median P/E
- Peer median EV/EBITDA
- Premium/discount to Mastercard
- Premium/discount to processor peers
- Historical multiple context
