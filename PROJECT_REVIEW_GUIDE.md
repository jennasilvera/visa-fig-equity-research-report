# Project Review Guide

## Purpose

This guide is designed for recruiters, bankers, equity research analysts, and buy-side investors reviewing the Visa FIG Equity Research Report repository.

The project is intended to demonstrate professional-level payments sector research, financial analysis, valuation thinking, and investment thesis development.

---

## Recommended Review Path

### 5-Minute Review

1. Read the repository README
2. Open `tearsheet/Visa_One_Page_Tearsheet.md`
3. Skim `investment_memo/Visa_Investment_Committee_Memo.md`

### 15-Minute Review

1. Review the full equity research report in `report/`
2. Open `model/Visa_Institutional_Model_v2.xlsx`
3. Read `investment_memo/variant_perception.md`
4. Review `competitive_analysis/visa_vs_mastercard.md`
5. Review `risk/regulatory_risk_framework.md`

### Full Review

1. Review the institutional model
2. Review the valuation package in `valuation/`
3. Review the payments ecosystem analysis in `industry/`
4. Review the competitive analysis in `competitive_analysis/`
5. Review the earnings analysis package in `earnings/`
6. Review source and methodology documentation
